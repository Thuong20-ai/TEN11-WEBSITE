# TEN11 — Website concept

Static site (a single `index.html`, no build step).

## Deploy on GitHub Pages
1. Upload all files in this folder to the root of a new repo (branch `main`).
2. Repo → **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `/ (root)` → Save.
3. After ~1 minute the site is live at `https://<username>.github.io/<repo-name>/`.
